# Eternal Medical Care Hospital (EMC)

A beginner-friendly, responsive front-end portfolio project built with HTML, CSS, and vanilla JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About us
- `services.html` — Departments with live search
- `doctors.html` — Demonstration doctor profiles with search and department filter
- `pharmacy.html` — Illustrative products and a demonstration cart
- `diagnostics.html` — Diagnostic information and client-side demo form
- `news.html` — Sample articles, search, category filter, and modal
- `contact.html` — Visitor information and demo appointment form

## Run in VS Code
1. Extract the ZIP file.
2. Open the `integrated-medical-care` folder in VS Code.
3. Open `index.html` in a browser, or install the Live Server extension and select **Open with Live Server**.
4. Use the navigation links to visit each page.

## Important notes
- This is a front-end learning project, not a real hospital service.
- Doctor profiles, sample articles, and product listings are fictional examples.
- Forms only validate in the browser. They do not save or send data.
- The pharmacy cart is a demonstration; it does not create real orders.
- Images and Google Fonts are loaded from external services, so an internet connection is needed for them. Replace image URLs with locally licensed images before publishing.
- Replace placeholder contact details only with verified details if you have permission to represent a real organisation.

## Concepts to practise
- Semantic HTML: `header`, `nav`, `main`, `section`, `article`, `footer`, `form`
- CSS: variables, Grid, Flexbox, media queries, hover states, focus styles
- JavaScript: DOM selection, event listeners, filtering, form validation, modal dialog, and updating text
